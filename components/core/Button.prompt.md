Pill-shaped CTA button in four variants — use `primary` for the single most important action per screen (booking, reserving).

```jsx
<Button variant="primary" size="md">Reserva tu cita</Button>
<Button variant="outline" size="sm">Ver servicios</Button>
```

Variants: `primary` (lemon fill, charcoal text — the booking CTA), `dark` (charcoal fill, bone text), `outline` (charcoal ring, transparent), `ghost` (text-only, for tertiary actions). Sizes: `sm` `md` `lg`. Press state is a subtle scale-down, never a hue change (protects the brand yellow).
