# Stigma — Instagram Carousel UI Kit

A click-through recreation of a branded Instagram carousel post (the account's top-performing format per the brand manual — ~3.6× the views of reels). Slide types: **Hook** (charcoal, serif headline, sparkle accents), **Tip** (bone background, numbered tip, magenta numeral), **Before/After** (the "antes que nadie ve" transformation reveal, built on `TransformationCard`'s visual language), **CTA** (lemon background, booking button, handle).

Swap the placeholder `foto`/`antes`/`después` blocks for real transformation photography — none was supplied.
