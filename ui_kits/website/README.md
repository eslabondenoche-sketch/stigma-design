# Stigma — Website UI Kit

One-page marketing site recreation: sticky header, hero, services grid, transformations gallery, testimonials, footer, and a click-through booking modal (service → time slot → confirmation). Built from the design system's `Button`, `Badge`, `ServiceCard`, `TransformationCard`, `TestimonialCard`, and `SparkleAccent` components — no new UI invented here, only the layout composing them per the brand manual's "Página web" application guidance (charcoal base, lemon CTAs, serif headlines, mobile-first).

No real product photography was supplied — before/after and testimonial photo slots are placeholders (`foto` label) ready to swap for real images.
